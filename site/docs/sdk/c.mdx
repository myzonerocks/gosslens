The other SDKs are wrappers over this. Linking the archive and including the
header gives you everything they have, in the shape they all call.

If you are wrapping this for another language, read [writing your own
SDK](/docs/binding/writing-an-sdk) alongside this page.

## Linking

Include `gosslens.h` and link the archive for your target. It is C99 and
includes nothing beyond `stdint.h`, `stddef.h` and `stdbool.h`, so it drops
into an existing build with no C++ runtime.

## The shape of every call

- Functions that can fail return `goss_status`. There is no errno and nothing
  throws.
- Handles are opaque pointers. Only `goss_engine` and `goss_session` cross.
- Buffers are caller-owned: you pass a pointer and a capacity, and the call
  writes how much it used.
- Vectors cross as pointers to fixed-size arrays, never as loose floats.
- Everything is graph-thread unless the header marks it any-thread.

## Starting up

```c
#include <gosslens.h>

if ((goss_abi_version() >> 16) != GOSS_ABI_MAJOR) return 1;
if (goss_abi_check(GOSS_ABI_VERSION) != GOSS_OK) return 1;

uint64_t caps = goss_capabilities();

goss_engine *engine = NULL;
goss_engine_config engine_config = { .texture_pool_capacity = 8, .staging_pool_capacity = 4 };
if (goss_engine_create(&engine_config, &engine) != GOSS_OK) return 1;

goss_session *session = NULL;
goss_session_config session_config = { .frame_budget_us = 8000, .reserved = 0 };
if (goss_session_create(engine, &session_config, &session) != GOSS_OK) {
    goss_engine_destroy(engine);
    return 1;
}
```

## Shutting down

```c
goss_session_destroy(session);
goss_engine_destroy(engine);
```

Sessions first, then the engine, on the thread that created them.

## Memory the engine hands back

```c
void *block = goss_alloc(size);
goss_free(block, size);
```

Free what the engine allocated with `goss_free` and nothing else. Your
allocator did not make it and cannot release it.
