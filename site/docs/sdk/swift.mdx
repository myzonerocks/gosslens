This is the complete guide for an iOS app. It goes in the order you will build
in: open the engine, get frames in, see what is there, draw back, then
everything the engine can do once that loop runs.

## Install

```swift
// Package.swift
dependencies: [
    .package(url: "https://github.com/myzonerocks/gosslens", from: "0.14.0"),
],
targets: [
    .target(name: "YourApp", dependencies: [
        .product(name: "Gosslens", package: "gosslens"),
    ]),
]
```

The package embeds an XCFramework with the device and simulator slices. No
toolchain, no build step, no post-install script.

## Check the build before you trust it

```swift
import Gosslens

try Gosslens.abiCheck()
let version = Gosslens.abiVersion()

let caps = Gosslens.capabilities()
guard caps.contains(.tracking) else { /* this build perceives nothing */ }
```

`Capabilities` is an `OptionSet`: `.tracking`, `.segmentation`, `.mlInference`,
`.diffusion`, `.beauty`, `.physics`, `.videoTextures`, `.photoCapture`,
`.recording`, `.fileIo`.

A stub build answers every call and computes nothing, and it looks exactly like
a camera pointed at a wall. Read this once at startup and keep it.

## Engine and session

```swift
let engine = try GossEngine.create(
    config: GossEngineConfig(texturePoolCapacity: 8, stagingPoolCapacity: 4)
)

let session = try GossSession.create(
    engine: engine,
    config: GossSessionConfig(frameBudgetUs: 8_000)
)
```

Zero in either config means the engine chooses. One engine per app; one session
per stream of frames.

`GossSession.create` keeps a strong reference to the engine, so the engine
cannot be released while a session still draws.

## Frames in

### The zero-copy path

Frames arrive as `CVPixelBuffer` and reach the engine as Metal textures through
one long-lived texture cache.

```swift
func captureOutput(_ output: AVCaptureOutput,
                   didOutput sampleBuffer: CMSampleBuffer,
                   from connection: AVCaptureConnection) {
    guard let pixels = CMSampleBufferGetImageBuffer(sampleBuffer) else { return }

    let desc = GossFrameDesc(
        width: UInt32(CVPixelBufferGetWidth(pixels)),
        height: UInt32(CVPixelBufferGetHeight(pixels)),
        pixelFormat: .nv12,
        colorStandard: .bt709,
        colorRange: .video,
        rotationDegrees: 90,
        mirrored: isFrontCamera,
        timestampUs: timestampUs(sampleBuffer)
    )

    _ = session.submitHardwareBuffer(desc: desc, hardwareBuffer: pointer(to: pixels))
}
```

`GossFrameDesc` is the whole description of a frame: size, `GossPixelFormat`,
`GossColorStandard`, `GossColorRange`, rotation, mirroring and timestamp. Get
rotation and mirroring right here rather than in your own shader; the engine
needs them to place landmarks.

### The copy paths

These exist for bringing a surface up and for sources that are not the camera.
They are correct and they are slower, so do not ship on them.

```swift
try session.submitFrameCopy(y: y, yStride: yStride, uv: uv, uvStride: uvStride,
                            width: w, height: h, rotationDegrees: 90,
                            mirrored: false, timestampUs: ts)

try session.submitFrameRgbaCopy(rgba: pixels, stride: w * 4, width: w, height: h)
```

A named source, for a second stream alongside the camera:

```swift
_ = session.submitSourceHardwareBuffer(name: "overlay", desc: desc, hardwareBuffer: buffer)
```

### Report the frame, every frame

```swift
let level = session.reportFrame(frameTimeUs: elapsedUs, thermal: GossSession.platformThermal)
```

`platformThermal` reads `ProcessInfo.thermalState` for you, so there is no
excuse for passing a constant. The return is the [degradation
level](/docs/concepts/degradation) the engine settled on.

## Seeing what is there

### Trackers

Each tracker takes the model bytes you supply and a thread count.

```swift
try session.enableFaceTracking(taskBundle: faceTask, threads: 2)
try session.enableHandTracking(taskBundle: handTask, threads: 2)
try session.enablePoseTracking(taskBundle: poseTask, threads: 2)
try session.setPoseUpperBody(true)

session.disableFaceTracking()
session.disableHandTracking()
session.disablePoseTracking()
```

Enable per screen and disable on leaving. Three trackers at two threads each
will not fit a mid-range phone's budget.

### Segmentation, with your own model

```swift
try session.enableSegmentation(model: modelBytes, threads: 2)
session.disableSegmentation()
```

Pin what may load, before enabling the worker:

```swift
try session.allowModelDigest(sha256Bytes)   // 32 raw bytes
try session.clearModelAllowlist()
```

With no digests set, any model loads. See [bring your own
model](/docs/build/models).

### Text

```swift
try session.enableText(detector: detector, recognizer: recognizer,
                       dictionary: dictionary, detectSide: 320)
let readings = try session.readings()
let (live, refused) = try session.textCount()
try session.disableText()
```

`GossReading` carries what the frame says, where, how sure, and which line and
paragraph it belongs to, so you can reassemble a layout rather than collect
words.

### The record

```swift
let json = try session.perceptionJson()
let packed = try session.perceptionSnapshot(select: GossSession.selectAll)
```

Both take a selection mask. A face filter asks for faces and the engine does
not serialise planes and text nobody reads. See [the perception
record](/docs/concepts/perception).

### Events

```swift
let (events, dropped) = try session.pollEvents(capacity: 64)
```

Drain once per frame. `dropped` is how many were lost because the ring filled,
and a climbing number is your earliest warning that the host is behind. Surface
it rather than discarding it.

## Drawing back

```swift
try engine.initRenderer(surface: layerPointer, width: w, height: h)
engine.resize(width: w, height: h)
try engine.renderFrame(session: session)
```

For a `CVPixelBuffer` you can hand to AVFoundation or a preview layer:

```swift
let output = GossLiveOutput(engine: engine, device: device, width: w, height: h)
if let buffer = output?.nextFrame(session: session) { /* present it */ }
```

Straight into a Metal texture you own:

```swift
_ = engine.renderToLiveTexture(session: session, texture: texturePointer,
                               width: w, height: h)
_ = engine.releaseLiveTexture(texture: texturePointer)
```

Read the composed frame back without presenting it:

```swift
try engine.captureLiveFrame(session: session, into: pixelBuffer)
let bytes = try engine.captureLiveFrame(session: session, width: w, height: h)
```

## Lenses

```swift
_ = try session.activateLens(manifestJson: manifestData)
_ = try session.activateLensFromDirectory(bundlePath: path)
try session.provideLensAsset(name: "sparkle.png", bytes: assetData)
session.deactivateLens()
```

A lens is advanced with the signals it reacts to, once per frame:

```swift
try session.tickLens(dtUs: deltaUs, signals: GossLensSignals(
    hasFace: faces > 0,
    handsPresent: hands > 0,
    tap: tappedThisFrame,
    worldTrackingState: trackingState,
    audioLevel: level,
    blendshapes: blendshapes
))

let value = try session.parameterValue("spin_w")
```

Before activating, ask what a lens needs that this build lacks:

```swift
let missing = try Gosslens.lensCapabilitiesMissing(manifestJson)
```

See [the lens format](/docs/concepts/lenses).

## AR

### ARKit in one object

`GossWorldSource` is an `ARSessionDelegate` that feeds the engine for you:
frames, camera pose, projection, planes, anchors and the light estimate.

```swift
let world = GossWorldSource(session: session, viewport: view.bounds.size)
world.onFrame = { pixelBuffer, timestampUs in /* optional, for your own use */ }
world.start()
world.pause()

GossWorldSource.supportsSceneDepth
GossWorldSource.supportsMesh
```

Screen to world, with a depth you already have:

```swift
let point = world.worldPoint(at: tapLocation, depth: metres)
```

### Doing it by hand

If you run your own ARKit session, submit the same things yourself:

```swift
session.submitCameraPose(worldFromCamera: pose, projection: projection, timestampUs: ts)
session.submitWorldMesh(vertices: vertices, indices: indices)
```

### Asking the engine about the room

```swift
let hit = session.hitTest(screenX: x, screenY: y)
let ray = session.raycastWorldMesh(origin: origin, direction: direction)
let floor = session.floorPlaneID()
// .unknown, .floor, .wall, .ceiling, .table, .seat, .door, .window, .screen
let kind = session.planeKind(planeID: id)
let route = session.pathAcrossWorld(start: a, goal: b)
```

Fitting something onto a surface, given what is already there:

```swift
let spots = session.placeOn(
    width: 0.4, depth: 0.3, height: 0.2,
    occupants: [GossSession.Occupant(planeID: floor, x: 0.1, z: 0.2, width: 0.2, depth: 0.2)]
)
// each Placement carries planeID, position and freeFraction
```

Measuring, with the error its inputs carried:

```swift
if let m = session.measure(from: a, fromAccuracyM: 0.01, to: b, toAccuracyM: 0.01) {
    // m.metres, m.sigma, m.known
}
```

`sigma` is the point of this call. A distance without its error bar invites a
product to display four decimal places of noise.

### Two devices, one space

```swift
let mine = session.sharedLandmarks()
if let fit = session.alignShared(theirs) {
    // fit.transform, fit.rmsError, fit.matched
}
```

Check `rmsError` and `matched` before trusting the transform. An alignment from
too few landmarks is worse than none, because it looks like it worked.

## Capture and recording

```swift
let photo = try engine.capturePhoto(session: session)                 // png
let jpeg  = try engine.capturePhoto(session: session, as: .jpeg, quality: 85)

var config = GossSession.StillConfig()
config.width = 4032
config.height = 3024
config.supersample = 2
config.format = .heic
config.colorSpace = .displayP3
let still = try engine.captureStill(session: session, config: config)

try engine.requestScreenshot(path: path)
```

Video:

```swift
try engine.startRecording(session: session, path: path,
                          width: 1920, height: 1080,
                          bitrate: 12_000_000, hevc: true, realtime: true)
try engine.pauseRecording()
try engine.resumeRecording()
try engine.stopRecording()

let report = try engine.recordingReport()
```

`realtime: true` keeps the recording in step with the clock and drops work
rather than falling behind. That is what a live capture wants; an export wants
`false`.

## Audio

```swift
let output = GossAudioOutput(session: session)   // 48 kHz
try output.start()
try output.pump(frames: 800)
output.stop()

let mic = GossMicInput(session: session, engine: engine)
try mic.start()
mic.stop()
```

Feeding the engine audio yourself, and mixing a lens's output:

```swift
try engine.submitAudio(session: session, samples: samples, frameCount: n,
                       sampleRate: 48_000, channels: 1, timestampUs: ts)

let mixed = try session.mixOutputAudio(mic: micSamples, frameCount: n,
                                       sampleRate: 48_000, channels: 2)
try session.pullAudio(into: &buffer, frames: 800)
```

## Clips and screens

A video file as a frame source:

```swift
let clip = try session.openClip(path: path)
let info = try session.clipInfo(clip)
_ = try session.clipSubmitFrame(clip, timestampUs: ts)
try session.clipSeek(clip, targetUs: us)
try session.clipStep(clip, frames: 1)
try session.closeClip(clip)
```

A shared screen:

```swift
let screen = try session.openScreen(surfaceId: id, scale: 1)
_ = session.stepScreen(screen)
let mapped = try session.screenPoint(screen, x: x, y: y)
try session.closeScreen(screen)
```

## Annotations, memory and scope

```swift
try session.annotate(annotation, text: "note")
try session.annotationRemove(id)
try session.annotationClear()

try session.memoryOpen(dim: 384, maxEntries: 4096)
try session.remember(id: 1, embedding: vector)
let hits = try session.memorySearch(query, k: 8)
try session.forget(id: 1)
let saved = try session.memorySave()
try session.memoryLoad(saved)
let sealed = try session.memorySaveSealed(key: key, nonce: nonce)
try session.memoryLoadSealed(key: key, bytes: sealed)
try session.memoryClose()

try session.setScope(
    sections: sections,
    verbs: GossSession.verbMask([.submitFrame, .activateLens, .enableTracking])
)
let current = try session.scope()
```

The verbs are `.annotate`, `.egress`, `.record`, `.remember`, `.searchMemory`,
`.openClip`, `.captureScreen`, `.submitFrame`, `.submitWorld`, `.submitAudio`,
`.audioOut`, `.sealMemory`, `.activateLens`, `.loadModel`, `.enableTracking`
and `.retouch`. Each carries the engine's own `name`, so a permission prompt
reads as words rather than a bitmask.

Scope only narrows. Widening means a new session.

## Measuring

```swift
let engineReport = try engine.engineReport()
let sessionReport = try session.sessionReport()
```

The engine report carries the renderer backend, whether the zero-copy import is
actually in use, and every pool's capacity, live count, peak and exhaustion
count. `zeroCopyImport` false on a device means your frames are being staged:
that is an integration bug, not an engine limit.

The session report carries frames submitted and rendered, the degrade level and
its transition count, per-subsystem analysis counts, `nodesDegraded` and
`nodeReportsLost`.

Tell the engine when the app is interrupted, so it does not read a stall as
thermal pressure:

```swift
try session.reportInterruption(.backgrounded)
```

## Threads and lifetimes

`GossEngine` and `GossSession` are `@unchecked Sendable`. That is the SDK
saying they are movable, not that they are thread safe.

- Keep one serial queue or one actor as the graph thread and make every call
  from it.
- A `for await` over camera frames can resume on any executor. That is the most
  common way an app ends up calling the engine from the wrong thread.
- `destroy()` is safe to call twice; only the first reaches the ABI, and
  `deinit` falls back to the same path.
- Destroy sessions before the engine.

See [threads and lifetimes](/docs/concepts/threading).

## Errors

Every failing call throws `GossStatus`. The ones worth handling by name:

| Status | What it means |
| --- | --- |
| `poolExhausted` | Every buffer is still held. Apply backpressure, do not grow the pool |
| `abiMismatch` | Package and library are from different majors. Refuse to run |
| `unsupported` | This build has no such subsystem. Check capabilities first |
| `rendererUnavailable` | No usable Metal device. Run without drawing, or say so |

## A whole frame, in order

```swift
session.submitHardwareBuffer(desc: desc, hardwareBuffer: buffer)
try session.tickLens(dtUs: dt, signals: signals)
try engine.renderFrame(session: session)
let json = try session.perceptionJson(select: faceSections)
let (events, dropped) = try session.pollEvents()
_ = session.reportFrame(frameTimeUs: elapsed, thermal: GossSession.platformThermal)
```

Six calls, one thread, no allocation on the common path.
